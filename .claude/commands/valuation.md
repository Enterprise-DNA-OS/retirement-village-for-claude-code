# /valuation

Use --agreed only when both sides agreed it in writing. Then show the updated exit working.

```bash
node scripts/village.mjs valuation "<contract>" --amount=<dollars> [--on=YYYY-MM-DD] [--agreed]
```

Use the configured database. Add `--json` when structured output helps. If a name is ambiguous, list the candidates and ask. Never guess a record and never send a message.
