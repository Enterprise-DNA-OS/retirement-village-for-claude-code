# /attention

Lead with the single most urgent item (an exit entitlement or a rule date always comes first), then the rest grouped by kind. Offer the matching draft for each.

```bash
node scripts/village.mjs attention [--village=<code>]
```

Use the configured database. Add `--json` when structured output helps. If a name is ambiguous, list the candidates and ask. Never guess a record and never send a message.
